# Movies

## Description

This Java program displays different movies organized into five movie genres.

It uses arrays, a two-dimensional array, and loops to organize and display the movies under each genre.

## Genres and Movies

- Action: Avengers, John Wick
- Comedy: The Hangover, Home Alone
- Horror: The Conjuring, Insidious
- Romance: Titanic, The Notebook
- Animation: Toy Story, Finding Nemo

## Concepts Used

- Arrays
- Two-Dimensional Arrays
- For Loops
- Enhanced For Loops
- String Data
- Console Output

## Program Structure

The program stores the movie genres in an array and the corresponding movies in a two-dimensional array.

A for loop is used to go through each genre, while an enhanced for loop displays the movies under each genre.

## File

Movies.java

## Purpose

This project demonstrates the use of arrays and loops in Java by organizing movies according to their respective genres.
