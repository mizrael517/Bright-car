# Student Attendance Checker

## Description

A Java assignment that demonstrates the use of arrays, loops, conditional statements, and methods to analyze student attendance.

## Features

- Stores student names and attendance percentages using arrays
- Displays each student's attendance
- Calculates the average attendance
- Checks whether each student has good or low attendance
- Uses separate methods to keep the program organized

## Concepts Used

- Arrays
- For loops
- For-each loops
- If-else statements
- Methods
- Parameters
- Return values

## How to Run

Open the Java file using a Java compiler such as *OnlineGDB* or *Visual Studio Code*.

For OnlineGDB:

1. Select *Java* as the language.
2. Paste the code into the editor.
3. Click *Run*.
